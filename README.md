# CMS KMB Widyodaya

Dashboard Content Management System (CMS) untuk organisasi Keluarga Mahasiswa Buddhis (KMB) Widyodaya.
Aplikasi ini dikembangkan dengan menggunakan React, Vite, Tailwind CSS v4, dan Supabase.

---

## 🚀 Panduan Memulai Cepat (Local Development)

### 1. Prasyarat
Pastikan Anda sudah menginstal **Node.js** (versi 16 atau lebih baru) di komputer Anda.

### 2. Instalasi Dependensi
Jalankan perintah berikut di terminal/PowerShell pada direktori proyek Anda:
```bash
npm install
```

### 3. Konfigurasi Lingkungan (`.env`)
Buka file `.env` di root direktori proyek, lalu masukkan kunci Supabase Anon Anda:
```env
VITE_SUPABASE_URL=https://aoiihdvginfyqaltdifi.supabase.co
VITE_SUPABASE_ANON_KEY=GANTI_DENGAN_SUPABASE_ANON_KEY_ANDA
```
*Catatan: Dapatkan **Anon Key** dari dashboard Supabase Anda di menu Settings > API.*

### 4. Jalankan Server Pengembangan
Untuk menjalankan aplikasi secara lokal dengan Hot Module Replacement (HMR):
```bash
npm run dev
```
Buka browser Anda dan akses tautan yang tertera di terminal (biasanya `http://localhost:5173`).

### 5. Bangun untuk Produksi (Build)
Untuk menguji hasil kompilasi produksi:
```bash
npm run build
```

## 🗄️ Skema Database Supabase

Untuk menjalankan otorisasi dan CRUD dengan benar, jalankan SQL query berikut di **SQL Editor** pada Dashboard Supabase Anda:

### 1. Tabel Pengguna (`public.user`)
Tabel ini memetakan pengguna yang terdaftar di Supabase Auth ke tingkat izin akses mereka.
```sql
CREATE TABLE public.user (
    user_id uuid PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
    email text UNIQUE NOT NULL,
    access boolean DEFAULT false NOT NULL,
    created_at timestamp with time zone DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Trigger Otomatis: Saat user baru mendaftar di Supabase Auth,
-- buat entri baru secara otomatis di tabel public.user dengan access default FALSE
CREATE OR REPLACE FUNCTION public.handle_new_user()
RETURNS trigger AS $$
BEGIN
  INSERT INTO public.user (user_id, email, access)
  VALUES (new.id, new.email, false);
  RETURN new;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

CREATE TRIGGER on_auth_user_created
  AFTER INSERT ON auth.users
  FOR EACH ROW EXECUTE FUNCTION public.handle_new_user();
```

> [!TIP]
> **Mengubah Izin Akses:**
> Anda dapat mengubah nilai kolom `access` pengguna secara manual di tabel `public.user` lewat editor Supabase menjadi `TRUE` agar akun tersebut lolos pengecekan izin dan mendapatkan akses ke Dashboard CMS.

### 2. Tabel Konten (`public.content_management`)
Tabel ini menyimpan seluruh konten publikasi KMB Widyodaya.
```sql
CREATE TABLE public.content_management (
    content_id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title text NOT NULL,
    embed_link text NOT NULL,
    description text,
    created_at timestamp with time zone DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Aktifkan Row Level Security (RLS) jika diperlukan, atau
-- buat policy yang mengizinkan semua operasi bagi pengguna yang terotentikasi.
ALTER TABLE public.content_management ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow read for anyone" 
ON public.content_management FOR SELECT USING (true);

CREATE POLICY "Allow write/update/delete for authenticated users with permission" 
ON public.content_management FOR ALL 
TO authenticated
USING (
  EXISTS (
    SELECT 1 FROM public.user u
    WHERE u.user_id = auth.uid() AND u.access = true
  )
);
```
